## 1. 简介

PyLine 是一款桌面端曲线数字化工具，用于从截图或扫描图中**提取图表数据**，将折线图、散点图还原为可分析的 XY 数值数据集。

**适用场景**

- 论文、报告中图表的数据复原
- 老旧文献中只有图片、没有原始数据的情况
- 多条曲线数据的对比与叠加分析

**核心能力**

| 功能       | 说明                                         |
| ---------- | -------------------------------------------- |
| 坐标系支持 | 线性、对数、极坐标                           |
| 取点方式   | 手动逐点、自动颜色检测、自动图形检测（测试） |
| 数据编辑   | 表格增删、排序、移动平均/SG 平滑             |
| 数据导出   | CSV、TXT、Excel、JSON、复制到剪贴板          |
| 可视化对比 | 内置 matplotlib 图表页，支持导入外部数据叠加 |

## 2. 快速入门

> [!note] 
> 如果只是临时提取一次数据，不需要频繁管理项目，可以跳过创建项目, 直接将图片拖放至工作区, 添加曲线后直接进入校准和取点流程，最后导出数据即可。

通过以下 5 步完成第一次曲线数据提取：

### 步骤 1 — 新建项目

1. 点击首页的 **新建项目** 按钮，或按 `Ctrl+N`。
2. 在弹出的输入框中输入项目名称，点击确认。
3. 在文件夹选择对话框中选择保存位置。

PyLine 会在该目录下创建一个以项目名称命名的文件夹，内含 `.pyline` 项目文件和 `files/images/` 图片备份目录。

![新建项目](images/quickstart-new-project.png)

---

### 步骤 2 — 添加图片

1. 在**工作区**页面，点击左侧工具栏的 **添加图片** 按钮（`Ctrl+I`）。
2. 在弹出的文件对话框中选择目标图片（支持 PNG、JPG 等常见格式）。
3. 也可以直接将图片文件**拖放**到中间的图片查看器区域。

图片会自动备份到项目目录，并出现在左侧项目树中。

![添加图片](images/quickstart-add-image.png)

---

### 步骤 3 — 坐标校准

> ⚠️ 提取数据前必须先完成校准，否则输出的是像素坐标而非实际数值。

1. 点击工具栏的 **校准** 按钮（或按 `C`），进入校准模式。
2. 在图片上依次点击 4 个已知坐标值的位置：
   - 先点 **X 轴起点**（输入对应 X 值）
   - 再点 **X 轴终点**（输入对应 X 值）
   - 然后点 **Y 轴起点**（输入对应 Y 值）
   - 最后点 **Y 轴终点**（输入对应 Y 值）
3. 校准完成后，点击弹出对话框中的 **确认**。

详细说明见 [第 5 节 — 坐标校准](#5-坐标校准)。

![坐标校准](images/quickstart-calibration.png)

---

### 步骤 4 — 提取曲线数据

1. 在项目树中点击目标图片节点，展开后点击 **+** 添加新曲线（`Ctrl+Shift+N`）。
2. 点击工具栏的 **手动提取** 按钮（或按 `Q`）。
3. 在图片上沿曲线逐点单击，每次点击自动换算为实际坐标并记录到右侧表格。
4. 如有误点，按 `E` 切换到橡皮擦模式，点击错误点将其删除。

![手动取点](images/quickstart-extract.png)

---

### 步骤 5 — 导出数据

1. 在右侧面板切换到 **数据导出** 标签页。
2. 选择导出格式（CSV、Excel 等）。
3. 点击 **导出** 按钮，选择保存路径即可。

也可以点击 **复制到剪贴板**，直接粘贴到 Excel 或其他表格软件。

![数据导出](images/quickstart-export.png)

## 3. 界面布局

PyLine 工作区由三栏组成：

```
┌─────────────┬─────────────────────────────┬──────────────────┐
│  左栏       │         中栏                │      右栏        │
│  项目树     │       图片查看器            │  曲线数据表格    │
│  管理项目/  │  （工具栏 + 图片 + 状态栏） │  + 功能标签页    │
│  图片/曲线  │                             │  （导出 / 对比   │
└─────────────┴─────────────────────────────┴──────────────────┘
```

| 区域                  | 说明                                                     |
| --------------------- | -------------------------------------------------------- |
| **左栏 — 项目树**     | 显示所有已打开项目及其图片、曲线，支持右键菜单和拖放     |
| **中栏 — 图片查看器** | 主操作区，校准、取点、预览均在此进行；支持滚轮缩放       |
| **右栏 — 数据面板**   | 上方为曲线数据表格（实时显示 XY 坐标），下方为功能标签页 |
| **顶部导航**          | 切换首页 / 工作区 / 图表 / 设置四个主界面                |

**图片查看器工具栏**（中栏上下各一排）

- 上方工具栏：橡皮擦、清空点、撤销、重做
- 下方工具栏：颜色采样、点形状、点大小、平滑

**状态栏**（图片查看器底部）显示当前鼠标在图片上的像素坐标和换算后的实际坐标。

![界面布局](images/ui-layout.png)

## 4. 项目管理

### 4.1 新建与打开项目

| 操作         | 方法                                                     |
| ------------ | -------------------------------------------------------- |
| **新建项目** | 首页点击「新建项目」按钮，或工作区按 `Ctrl+N`            |
| **打开项目** | 首页点击「打开项目」，或按 `Ctrl+O`，选择 `.pyline` 文件 |
| **最近项目** | 首页下方列表直接点击重新打开                             |
| **保存项目** | 按 `Ctrl+S` 或点击工具栏保存按钮                         |
| **关闭项目** | 按 `Ctrl+W` 或点击工具栏关闭按钮                         |

> 💡 PyLine 支持同时打开多个项目，在项目树中点击切换。

### 4.2 项目结构

```
项目名称/
├── 项目名称.pyline       # 项目元数据（JSON 格式，可分享）
└── files/
    └── images/           # 图片备份（相对路径，文件夹可移动）
```

### 4.3 添加与管理图片

- **添加图片**：点击工具栏 *添加图片* 按钮（`Ctrl+I`），或直接将图片文件拖放到图片查看器
- **重命名**：在项目树中**右键**节点 → 重命名
- **删除**：在项目树中**右键**节点 → 删除（备份文件一并清除）
- **跨项目移动**：在项目树中直接将图片节点**拖放**到另一个项目节点下

### 4.4 添加与管理曲线

1. 在项目树中单击目标图片节点（先选中图片）。
2. 点击工具栏 **添加曲线** 按钮（`Ctrl+Shift+N`），或右键图片节点 → 添加曲线。
3. 在项目树中单击曲线节点即可切换当前操作曲线。
4. 双击曲线节点可重命名；右键可删除。

## 5. 坐标校准

> ⚠️ **必读前置**：数据提取前必须完成校准，否则记录的是像素坐标。

### 5.1 选择坐标系类型

在工作区右侧的 **坐标类型** 选择框中选择对应坐标系，或在校准对话框弹出时选择：

| 坐标系     | 适用情况                          |
| ---------- | --------------------------------- |
| **线性**   | 最常用；X 轴和 Y 轴均为等间距刻度 |
| **对数**   | X 轴或 Y 轴为对数刻度             |
| **极坐标** | 图表以极径/角度表示数据           |

### 5.2 线性 / 对数坐标校准

1. 按 `C` 或点击工具栏 **校准** 按钮进入校准模式。
2. 状态栏会提示当前需要点击的校准点。
3. 依次点击 **4 个**已知坐标值的像素位置：

   | 顺序 | 点位     | 说明                        |
   | ---- | -------- | --------------------------- |
   | 1    | X 轴起点 | 对应 X 轴最小刻度，如 `0`   |
   | 2    | X 轴终点 | 对应 X 轴最大刻度，如 `10`  |
   | 3    | Y 轴起点 | 对应 Y 轴最小刻度，如 `0`   |
   | 4    | Y 轴终点 | 对应 Y 轴最大刻度，如 `100` |

4. 点击完 4 个点后，弹出对话框输入每个点对应的**实际坐标值**，确认后校准完成。

> 💡 校准点不需要是坐标轴的交叉点，只需是刻度线上坐标值已知的任意位置。  
> 💡 如需微调校准点位置，可在对话框中使用方向键微移。

![线性校准](images/calibration-linear.png)

### 5.3 极坐标校准

1. 按 `C` 进入校准模式，选择**极坐标**类型。
2. 依次点击 **2 个**点：

   | 顺序 | 点位         | 说明                   |
   | ---- | ------------ | ---------------------- |
   | 1    | 原点（极点） | 极坐标系的中心         |
   | 2    | 参考点       | 已知角度和极径的任意点 |

3. 在弹出对话框中输入参考点的**实际角度值**和**极径值**，确认后校准完成。

![极坐标校准](images/calibration-polar.png)

## 6. 曲线提取

PyLine 提供三种取点方式，可根据图片质量和曲线特征选择。

### 6.1 手动取点

最精准的方式，适合曲线复杂或噪点多的图片。

1. 在项目树中选中目标曲线。
2. 按 `Q` 或点击工具栏 **手动提取** 按钮，光标变为十字准星。
3. 在图片上**逐一点击**曲线上的数据点。
4. 每个点击立即出现在图片上，并同步写入右侧数据表格。
5. 按 `Escape` 退出取点模式。

**删除误点**

- 按 `E` 切换到橡皮擦模式，点击已有数据点将其删除。
- 或使用 `Ctrl+Z` 撤销上一个操作。

![手动取点](images/extract-manual.png)

### 6.2 自动颜色检测

适合曲线颜色明显区别于背景的图片，可批量提取整条曲线。

1. **采样颜色**：在下方工具栏点击颜色采样按钮，在图片上单击目标曲线颜色，或手动打开颜色对话框调整。
2. **调整参数**：
   - **容差**：颜色相似度阈值，越大匹配范围越广，但可能误匹配。
   - **采样步长**：每隔多少像素取一个点，越小点越密集。
3. **执行检测**：按 `A` 或点击工具栏 **自动检测** 按钮，预览点以另一颜色叠加显示。
4. **确认应用**：预览满意后，按 `Ctrl+Enter` 或点击 **应用检测结果**，将预览点写入当前曲线。

> 💡 若背景有干扰，先用 [蒙版](#7-蒙版) 限定检测范围再执行。

![自动颜色检测](images/extract-auto-color.png)

### 6.3 自动图形检测（测试功能）

> ⚠️ 此功能目前处于测试阶段，结果可能不稳定。

1. 在图片上通过框选操作划定包含目标图形的区域。
2. PyLine 会自动识别并生成数据点。
3. 确认后应用结果。

![自动图形检测](images/extract-auto-shape.png)

## 7. 蒙版

蒙版用于**限定自动检测的有效区域**，排除图中标注文字、图例、其他曲线等干扰元素。

### 7.1 绘制蒙版

| 工具         | 说明                                 |
| ------------ | ------------------------------------ |
| **框选蒙版** | 在图片上拖动鼠标绘制矩形区域         |
| **画笔蒙版** | 自由涂刷任意形状区域，适合不规则区域 |

可绘制多个蒙版区域，效果叠加。

### 7.2 蒙版模式

点击工具栏的模式切换按钮，在两种模式之间切换：

| 模式                 | 效果                                         |
| -------------------- | -------------------------------------------- |
| **屏蔽模式**（默认） | 蒙版覆盖区域内**不检测**，用于排除干扰       |
| **感兴趣模式**       | **仅在**蒙版覆盖区域内检测，用于精确框定范围 |

### 7.3 清除蒙版

- 按 `Ctrl+Shift+Delete`，或点击工具栏 **清除蒙版** 按钮。
- 橡皮擦工具（`E`）切换到蒙版后，点击已有蒙版区域可单独删除该区域。

![蒙版示例](images/mask-example.png)

## 8. 数据编辑与导出

### 8.1 数据表格

右侧面板上方的表格实时显示当前选中曲线的所有 XY 数据点。

| 操作            | 方法                                        |
| --------------- | ------------------------------------------- |
| **删除数据点**  | 鼠标多选行 → 右键菜单删除，或按 `Delete` 键 |
| **排序**        | 点击**表头** X 或 Y 列名，交替切换升序/降序 |
| **撤销 / 重做** | `Ctrl+Z` / `Ctrl+Y`（最多支持 50 步历史）   |

### 8.2 曲线平滑

在下方工具栏中展开平滑选项：

| 算法               | 说明                             |
| ------------------ | -------------------------------- |
| **移动平均**       | 简单平滑，适合轻微噪点           |
| **Savitzky-Golay** | 保形平滑，适合保留峰值形状的情况 |

调整窗口大小后点击 **应用平滑**，结果会写入数据点；可撤销。

### 8.3 数据导出

在右侧 **数据导出** 标签页中：

| 格式              | 说明                               |
| ----------------- | ---------------------------------- |
| **CSV**           | 逗号分隔，通用文本格式             |
| **TXT**           | 制表符分隔文本                     |
| **Excel (.xlsx)** | 多曲线时每条曲线独立一个 Sheet     |
| **JSON**          | 含曲线名称、颜色、坐标类型等元数据 |
| **复制到剪贴板**  | 直接粘贴到 Excel 或 Numbers        |

可选择 **仅导出当前曲线** 或 **导出全部曲线**。

![数据导出面板](images/export-panel.png)

## 9. 图表与数据对比

点击顶部导航的 **图表** 进入图表页，用于可视化当前项目的曲线，并支持导入外部数据叠加对比。

### 9.1 查看项目曲线

图表页自动加载当前项目中所有曲线并绘图。左侧 **曲线选择** 列表中勾选或取消勾选来控制显示/隐藏。

### 9.2 样式设置

1. 在曲线列表中单击选中目标曲线（可多选）。
2. 在 **曲线样式** 区域：
   - 点击颜色按钮选择线条颜色
   - 下拉菜单选择线型（实线、虚线、点线、散点等 9 种样式）
3. 点击 **刷新** 按钮更新图表显示。

### 9.3 导入外部数据叠加对比

1. 点击 **导入数据** 按钮，选择外部文件（支持 CSV、TXT、JSON 等格式）。
2. 导入的曲线出现在曲线列表底部（标注为「导入」）。
3. 可为导入曲线单独设置颜色和线型。
4. 点击 **删除导入** 可删除选中的导入曲线；**清除绘图** 删除所有导入数据。

### 9.4 坐标轴设置

在左侧 **坐标轴** 区域：

- 手动输入 X / Y 轴的最小值和最大值以固定范围（留空则自动范围）
- 输入 X / Y 轴标签文字

### 9.5 导出图表

点击 **导出图片** 按钮，支持以下格式：

| 格式    | 说明               |
| ------- | ------------------ |
| **PNG** | 位图，适合文档插图 |
| **SVG** | 矢量图，可无损缩放 |
| **PDF** | 矢量图，适合论文   |

![图表页面](images/chart-compare.png)

## 10. 设置

点击导航栏的 **设置** 进入设置页面。

### 10.1 主题

在 **外观** 卡片中通过下拉菜单切换：

| 选项         | 说明                         |
| ------------ | ---------------------------- |
| **浅色**     | 始终使用浅色主题             |
| **深色**     | 始终使用深色主题             |
| **跟随系统** | 自动跟随操作系统主题（默认） |

切换后即时生效，无需重启。

### 10.2 快捷键自定义

在 **快捷键** 卡片中：

1. 找到要修改的操作。
2. 点击对应的输入框，按下新的快捷键组合。
3. 若与其他快捷键冲突，输入框下方会出现红色提示。
4. 点击 **应用快捷键** 保存，修改后立即生效。
5. 点击 **恢复默认** 重置所有快捷键为出厂设置。

![设置页面](images/settings.png)

## 11. 附录：快捷键速查

### 全局操作

| 快捷键   | 功能     |
| -------- | -------- |
| `Ctrl+N` | 新建项目 |
| `Ctrl+O` | 打开项目 |
| `Ctrl+W` | 关闭项目 |
| `Ctrl+S` | 保存项目 |
| `Ctrl+Z` | 撤销     |

### 项目树
