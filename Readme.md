# PyLine

从图片中提取曲线数据的桌面工具。

将科学论文、报告中的图表截图还原成可分析的 XY 数值数据集。

## 功能

- **项目管理** — 多项目同时打开，层级树形展示（项目 → 图片 → 曲线）
- **坐标校准** — 支持线性、对数、极坐标三种坐标系
- **曲线提取** — 手动点击取点，或按颜色自动检测
- **蒙版** — 框选/画笔绘制感兴趣区域，过滤自动检测范围
- **数据编辑** — 撤销/重做、表格删除、曲线平滑
- **导出** — CSV、Excel、JSON、TXT、复制到剪贴板
- **图表** — 可视化对比，支持导入外部数据，导出为 PNG/SVG/PDF
- **快捷键** — 全部操作快捷键可自定义

## 安装与运行

```bash
uv sync
uv run main.py
```
