# PyLine

> 从图片中提取曲线数据的桌面工具

PyLine 是一款基于 PySide6 + QFluentWidgets 的桌面应用，专为将科学论文、报告中的图表截图还原成可分析的 XY 数值数据集而设计，支持手动取点、自动颜色检测、多格式导出和图表可视化对比。

---

## 功能概览

- **多项目管理** — 同时打开多个 `.pyline` 项目，层级树形展示
- **坐标校准** — 支持线性、对数、极坐标三种坐标系
- **手动 / 自动曲线提取** — 点击取点或按颜色自动检测
- **蒙版系统** — 框选或画笔绘制感兴趣区域 / 屏蔽区域
- **数据编辑** — 撤销/重做、表格删除、曲线平滑
- **多格式导出** — CSV、Excel、JSON、TXT、剪贴板
- **图表可视化** — matplotlib 渲染，支持导入外部数据对比
- **快捷键自定义** — 全部操作快捷键可在设置页修改

---

## 界面页面

### 首页

- 显示最近打开的项目列表（含项目名、路径、最后打开时间）
- 支持新建项目、打开已有 `.pyline` 文件
- 点击最近项目行直接加载；支持逐条删除历史记录

### 工作区

核心页面，包含三栏布局：

| 区域 | 内容 |
|------|------|
| 左侧 | 项目树（项目 → 图片 → 曲线）+ 工具栏 |
| 中央 | 图片查看器 + 悬浮工具栏 |
| 右侧 | 功能区（图片选点 / 数据导出） |

### 图表页

- 列出所有已提取曲线，多选后在 matplotlib 画布中绘制
- 支持导入外部数据文件（CSV/TXT/DAT/JSON/npy）进行对比
- 每条曲线可设置颜色和线型，支持导出为 PNG/SVG/PDF

### 设置页

- 切换主题（浅色 / 深色 / 跟随系统）
- 自定义全部操作的键盘快捷键，支持冲突检测，修改即时生效

## 坐标校准

进入校准模式前选择坐标类型：

| 类型 | 校准点数 | 说明 |
|------|---------|------|
| 线性 | 4 点 | X 轴首末 + Y 轴首末 |
| 对数 | 4 点 | 同上，映射到对数空间 |
| 极坐标 | 2 点 | 原点 O + 参考点 A（输入实际角度/极径） |

校准完成后，所有提取的像素坐标自动换算为实际坐标。

---

## 曲线提取

### 手动取点

选中曲线 → 按 `P` 进入提取模式 → 在图片上点击各数据点。

### 自动颜色检测

1. 通过颜色对话框或按 `从图片取色` 按钮采样目标曲线颜色
2. 调整**容差**（1–80）和**步长**（1–20 px）滑块
3. 按 `A` 执行检测，预览结果以黄色虚线圆点显示
4. 按 `Enter` 应用，或点击放弃

### 辅助选点

点击两个端点框定矩形或椭圆区域，在该区域内执行颜色检测，适合局部密集曲线。

## 蒙版系统

| 操作 | 说明 |
|------|------|
| 框选蒙版 | 拖动绘制矩形区域 |
| 画笔蒙版 | 任意路径涂刷区域 |
| 反转蒙版 | 切换感兴趣区域 / 屏蔽区域模式 |
| 清除蒙版 | `Ctrl+Alt+Delete` |

自动检测时蒙版过滤器自动生效。

---

## 数据编辑

- **撤销 / 重做**：`Ctrl+Z` / `Ctrl+Y`，最多保留 50 步历史
- **曲线平滑**：移动平均 或 Savitzky-Golay 滤波
- **数据表格**：实时显示当前曲线点坐标，支持点击表头排序、右键删除行（可撤销）
- **微调**：方向键按步长微调已选点位置

---

## 导出

在工作区 **"数据导出"** 标签页中：

| 格式 | 说明 |
|------|------|
| CSV | 单文件多曲线或每曲线独立文件 |
| Excel (`.xlsx`) | 每条曲线一个 Sheet |
| JSON | 含元数据（名称、颜色、坐标类型、校准信息） |
| TXT | 制表符分隔纯文本 |
| 剪贴板 | Tab 分隔，可直接粘贴到 Excel |

可选附加时间戳，导出范围可选当前曲线或全部曲线。

## 安装与运行

依赖 [uv](https://github.com/astral-sh/uv) 管理虚拟环境：

```bash
git clone <repo-url>
cd PyLine
uv sync
uv run main.py
```

### 主要依赖

| 包 | 用途 |
|----|------|
| `PySide6` | Qt6 GUI |
| `PySide6-Fluent-Widgets` | Fluent Design 组件库 |
| `pydantic` | 数据模型与序列化 |
| `opencv-python` | 图像处理（自动检测） |
| `numpy` | 数值计算 |
| `matplotlib` | 图表渲染 |
| `openpyxl` | Excel 导出 |

## 项目文件格式

`.pyline` 文件为标准 JSON，数据层级如下：

```
Project
├── name, id, created_at, updated_at, file_path
└── images[]
    ├── name, image_path
    ├── mask (polygons + include_mode)
    └── curves[]
        ├── name, color, point_shape
        ├── x_data[], y_data[]        # 像素坐标
        ├── x_actual[], y_actual[]    # 实际坐标（校准后）
        └── calibration               # 校准数据（可选）
```
